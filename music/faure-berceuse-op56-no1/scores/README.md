# Fauré working scores — retired version 1

The old automatic scores derive from the rejected Kong transcription. They are
removed from the current edition at the maintainer's cleanup request. No score
edition has been prepared for the selected Aria recording.

Historical source/PDF files remain available in [the retired edition](https://github.com/jochenwezel/open-sleep-music/tree/7a7b98a8d8bf7cd1e452817f14276bd7967de0a0/music/faure-berceuse-op56-no1/scores).
Do not use them as notation for the new Aria MIDI. Compact engraving metadata
is preserved in `sources/engraving-v1-retired.json` for traceability.
